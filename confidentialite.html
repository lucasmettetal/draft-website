DONNÉES & CONFIDENTIALITÉ

Politique de confidentialité.

Version de préparation — 6 novembre 2026.

Avant une diffusion générale : les coordonnées de l'éditeur et les mentions légales adaptées à son statut doivent être complétées. Ce texte doit être revérifié avec les fonctionnalités de la version effectivement distribuée.

1. Présentation

DRAFT est un projet indépendant d'assistance à l'analyse de draft pour League of Legends. Le site vitrine et l'application Windows ont des traitements de données distincts.

2. Données du site web

Ce site statique ne propose pas de compte, de formulaire, de publicité ou d'outil d'analyse d'audience intégré. Il ne place pas de cookie de suivi applicatif. L'hébergeur peut traiter l'adresse IP et des journaux techniques pour servir et protéger le site. Les polices sont chargées depuis Google Fonts, ce qui peut conduire le navigateur à contacter ce fournisseur.

3. Données de l'application

Selon les versions, les profils de champions, préférences, calculs et historiques de parties importées sont conservés localement sur le PC. L'import d'historique Riot est déclenché volontairement par l'utilisateur et nécessite une connexion aux services Riot. Certaines données, notamment le Riot ID, peuvent figurer dans les fichiers locaux. L'application n'intègre pas de télémétrie centrale déclarée ; ceci doit être confirmé pour chaque version publiée.

4. Clé API Riot

Le mécanisme d'import a été conçu pour utiliser une clé fournie par l'utilisateur pendant l'opération, sans l'enregistrer dans les fichiers locaux. Ne partagez jamais cette clé dans un ticket, une capture ou un échange public. La conformité de ce fonctionnement doit être revérifiée avant une diffusion générale.

5. Conservation et suppression

Les données locales restent sous le contrôle de l'utilisateur. Leur suppression dépend de l'emplacement des fichiers de configuration et des sauvegardes de la version installée. Ne supprimez pas un dossier sans avoir conservé les sauvegardes souhaitées.

6. Liens externes

Les liens vers GitHub et Riot Games mènent à des services tiers appliquant leurs propres politiques de confidentialité.

7. Contact

Un contact dédié aux demandes relatives aux données doit être ajouté avant la distribution publique. Les problèmes techniques non sensibles peuvent être signalés via GitHub Issues. Ne publiez pas de données personnelles dans une issue.
